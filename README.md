## 🧪 How I like to build

```text
                         ┌──────────────────┐
                         │      PROBLEM      │
                         └────────┬─────────┘
                                  │
                         requirements first
                                  ▼
                    ┌──────────────────────────┐
                    │        ARCHITECTURE       │
                    │ components · boundaries  │
                    │ trade-offs · failure     │
                    └────────────┬─────────────┘
                                 │
                                 ▼
                    ┌──────────────────────────┐
                    │      IMPLEMENTATION       │
                    │ APIs · data · models     │
                    │ workers · validation     │
                    └────────────┬─────────────┘
                                 │
                                 ▼
                    ┌──────────────────────────┐
                    │        EVALUATION        │
                    │ metrics · tests · logs   │
                    │ does it actually improve?│
                    └────────────┬─────────────┘
                                 │
                                 ▼
                         ┌──────────────┐
                         │   ITERATE    │
                         └──────┬───────┘
                                │
                                └──────────→ back to the problem
```
