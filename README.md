## 🧪 How I like to build

```text
Problem
  │
  ├── What are the actual requirements?
  │
  ▼
Architecture
  │
  ├── What components do we need?
  ├── Why do they exist?
  └── Where can they fail?
  │
  ▼
Implementation
  │
  ├── APIs · data · models · workers
  └── tests · validation · observability
  │
  ▼
Evaluation
  │
  ├── Does it actually work?
  └── Can we measure improvement?
  │
  ▼
Iteration
```

I'm particularly interested in the engineering questions behind AI products: **retrieval quality, model evaluation, API design, asynchronous work, reliability, cost, failure modes and system trade-offs.**
